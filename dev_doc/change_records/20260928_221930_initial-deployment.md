# 初始本地中文检测服务

完成日期：2026-09-28。范围依据：用户要求安装前序聊天中支持中文的本地检测模型，完成通路试跑、统一接口，并参考指定 yadof 项目建立文档系统。

## 完成内容

- 当前工作区建立 Python 虚拟环境及 CUDA 依赖，安装 MPU 中文 v3、v3 Short、v2 和 HC3 中文四个权重。
- 下载先直连，Hugging Face 直连超时后回退环境代理。模型采用固定 commit、官方 LFS 校验及本地文件清单。
- 提供 Python、CLI、HTTP、标准库客户端，支持长文分块、原文位置和重叠权重。输出各模型独立分数，未加入判定门限。
- 准备作者样本及有来源的 HC3 人工/AI 样本；长文夹具只验证覆盖。
- 增加本机后台服务启停，记录并核对启动器/worker 身份，避免依赖受限环境的全局进程树操作。
- 建立 user_doc 与 dev_doc，含架构、模块说明、术语、环境、实验上下文、待办、历史和维护契约。

## 验证

32 次真实模型试跑、四模型离线加载、作者公式、CPU/GPU 一致性、全文覆盖全部通过。7 项接口/窗口契约测试通过；在 dissertation cwd 下完成 HTTP 和 CLI 调用、服务停止/重启验证。

原始证据及实际版本见 [安装与验证记录](../context/installation-validation.md)。

## 边界

没有对 dissertation 正式生成内容开展检测，也没有修改该工作区。没有用 smoke 样本估计准确率、选择模型或设门限。模型许可与排除候选的依据见 [来源说明](../context/model-sources.md)。
