# 新增六个中文检测分类器

完成日期：2026-09-29。

## 变更

用户要求安装新增中文候选，并确认范围为六个分类器。已增加 EnsemJudge BERT、EnsemJudge RoBERTa、AnxForever BERT v11c、yibo365 paperpass-v3、CMJ 和 bibbbu XLM-RoBERTa，连同原有四个模型共十个。

- 下载器支持按 ID 选择、checkpoint 子目录和独立 tokenizer 来源；全部新增权重与 tokenizer 固定 revision，逐文件记录 SHA-256 和原始来源。manifest 原子更新。
- EnsemJudge 两层分类头在本地适配，不运行远程仓库代码；加载器拒绝缺失、不匹配或多余权重，避免静默使用随机分类头。
- HTTP 检测及标注的模型列表上限随 catalog 更新；Python、CLI、HTTP 均可选六个新 ID，默认运行十模型。三档分档线保持原有可配置规则。
- smoke 和部署测试支持指定独立输出位置，历史四模型报告保留。现有本机服务已重启，实际十模型请求验证通过。
- 没有新增或升级依赖。按用户范围排除 LLM-Detector-Small-zh、EnsemJudge 大模型及完整集成。

## 验证与限制

67 个文件完整哈希检查、27 项契约测试、80 次基础模型样本试跑、12 次 NLPCC 补充试跑、十模型离线加载及 CPU/CUDA 对照、HTTP 和跨目录 CLI 调用全部完成。新增资源约 4.97 GB，总模型资源约 6.60 GB。

不同模型、不同来源样本存在明显分歧；未根据本轮样本调整标签、门限或温度，也不报告准确率。默认十模型可能改变“任一模型触发”的标注结果。详细证据见 [扩展验证](../context/model-expansion-validation.md) 与 [测试摘要](../../reports/model-expansion-20260929/README.md)。
