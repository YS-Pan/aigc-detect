# 可选英文模型与公开来源试跑

完成日期：2026-10-02。范围：用户要求执行“调研英文 AIGC 检测模型”聊天中的接入方案，并在改代码后联网寻找明确的英文人工/AIGC材料测试。

## 交付

- 安装并固定 HC3 English、Desklib v1.01、Fakespot 权重；与既有 bibbbu 组成可选英文四模型组。权重同级放入 models，manifest 保留来源、revision、大小和 SHA-256。
- Python / CLI / HTTP 检测、批量、标注支持显式 `language=zh/en`。默认仍为原中文十模型；显式IDs优先，英文模型按需加载。health 默认状态按中文组判断，各组就绪单列。
- 本地适配 Desklib 的 mask 平均池化单输出头及 sigmoid，完整检查 checkpoint 键与输出维度，保留离线、安全权重和512 token完整覆盖。无需新增运行依赖。
- 英文标注独立版本化边界，并要求显式旧任一模型策略；原中文 profile、分片、revision 和融合参数不变，拒绝将中文 profile 套到英文现场/缓存报告。下载、校验、旧中文 smoke、部署、拟合和公开样本脚本同步模型组边界。
- 归档20条来源文本：四个历史作者作品节选和HC3八组成对回答，共12条human、8条ai。每条保存来源、许可、revision/位置/字段及hash；检测只输入正文。同步用户指南、架构、模块说明和样本/报告入口。
- 本地editable包及受管理API更新到0.5.0，实际服务在127.0.0.1:8765启动。

## 验证与实际观察

86项契约回归通过；十三模型哈希及pip check通过；中文8样本×十模型真实离线、CPU/CUDA、公式与接口回归通过。英文20样本×四模型全文检测以及全部分段报告完成，另验证长窗口、作者公式、CPU/CUDA、网络阻断、HTTP路由和跨cwd CLI。完整英文输入共32776字符。

按全文原始0.90线，HC3 / Desklib / Fakespot / bibbbu在12条human上的高分计数为0、0、1、12；8条ChatGPT在四模型中均高分。bibbbu在这批英文人工材料上严重误报，包含它的任一模型规则不能用作可靠来源判定。没有据此调整门限、拟合英文融合或宣称准确率。

HC3样本与hc3-en训练明确重叠；历史著作未审计训练重叠。这批不能当作独立准确率验证，且AIGC只覆盖早期ChatGPT。RAID小批量接口返回500/超时，未列入测试样本。Gutenberg TXT响应在书尾前结束，所选四个完整节选均在保存范围内；快照只用于追溯这些节选，不是完整作品归档。
