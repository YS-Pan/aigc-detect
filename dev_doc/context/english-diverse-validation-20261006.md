## 基线诊断和两个固定改进

本地加载v2锁定五分类器：openai-base-en、openai-large-en、piratexx-en、mage-en、radar-vicuna-en；revision、35个资产文件hash均核对。float32、batch_size=8（模型原有更低上限生效）、token overlap=64，完整token覆盖；关闭全部梯度并assert模型eval，阻断socket网络访问。

v2拟合资料为0/1142人工误报、2/295生成单位命中；四篇新开发组为0/184、0/87。拟合+开发的五个原始分数中，只有OpenAI Large的1个生成窗口高于人工最大分；MAGE人写和生成的最高值相同，其他三个生成最高值低于人工最高值。这个单信号描述不构成所有纯分数组合的理论上限，但支持低误报端信号重叠仍是瓶颈。

仅执行生成前声明的两条路径，没有重新跑旧648候选、42/75候选融合或12种局部扫描：

1. `v2-human-calibration`：v2分数函数与分片全部固定；门限只能由拟合/开发/人工校准中的纯人工窗口最大logit加预声明0.1余量，并且不低于既有门限。
2. `presence-linear-refit`：同五个原始分数，重新拟合现有上层线性纯分数函数，目标改为窗口含任意生成字符；固定L2=10、人写权重20，没有参数网格。按作者组和标签桶归一化，按(paper, input hash, label)去重；不输入正文、作者、长度或文件身份。logit保留到1e-12，标准化截断±5；标签只用于维护期拟合和评价。不是新底层分类头，没有神经训练。

一次固定重拟合的15个作者组留出诊断：0/1142人工误报、0/295生成单位命中；每折重新标准化、拟合及取训练纯人工门限。两个候选开发结果均0/184、0/87，按预声明平手规则选门限校准。选择之后，所有纯人工机会共同校准；两条候选参数、选中ID、源码、基线profile、输入、训练数值、校准配置先写FREEZE，再评分验收。不存在依据验收结果换候选或再次调门限的步骤。
