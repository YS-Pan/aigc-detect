# 英文缓存的最难人工窗口排序实验

2026-10-04，用户要求执行[复盘聊天](codex://threads/01a10524-db1b-7421-90b5-16bffa676b1e)建议的第一步。本轮已完成预声明的小型实验，**没有改善检出，默认继续保留英文线性v2**。没有继续扩充RBF/MLP搜索，也没有开展后续数据构建或底层微调。

## 口径与方法

沿用用户确认的标签：窗口只要含有任何AIGC即是正例；完全人工窗口判正才是假阳性，包含原版和混合版本中的人工窗口。一个生成段与至少一个判正窗口有正长度交集即算命中。正例窗口内的人工字符不计误报。

固定v2的五分类器及revision、1600/400分片，直接读取已有缓存。只比较三个线性目标，各取三档L2，共9个候选：

- 普通窗口存在判别，使用按论文/类别平衡的交叉熵。
- 平均人工排序：每个混合生成段的相交窗口构成一个bag，与全部人工窗口平均比较。
- 最难人工排序：用人工最高分的平滑上界与生成段bag最大分的平滑下界比较，最小化`softplus(m+H-B)`，另加L2。运行仍仅接收五个模型分数。

`H=tau*logsumexp(s_h/tau)`，`B=tau*logmeanexp(s_w/tau)`，温度和间隔预声明。位置和来源身份只定义训练bag、分组、权重与评价，不进入预测函数。最终拟合用6篇论文的254个去重窗口、51个混合生成段bag；单独生成段不参与本轮训练。

三种目标各自的候选参数仅在原6篇拟合论文中选择。另做六篇嵌套逐论文留出，外层论文不进入内层选择、标准化、训练或门限。最终门限由拟合及2篇校准中的完全人工窗口决定；校准生成窗口不参与选参或门限。先冻结三类冠军和总体选择，再读取P07/P08缓存复测。全部十篇均为已见开发资料，不是新独立测试。

## 结果

| 范围 | 方法 | 完全人工窗口误报 | 混合生成段命中 |
|---|---|---:|---:|
| 六篇嵌套留出 | 普通存在判别 | 0/390 | 0/51 |
| 六篇嵌套留出 | 平均人工排序 | 4/390 | 1/51 |
| 六篇嵌套留出 | 最难人工排序 | 4/390 | 0/51 |
| P07/P08冻结复测 | 现有v2 | 0/58 | 2/12 |
| P07/P08冻结复测 | 最难人工排序 | 0/58 | 0/12 |
| 全部十篇，含拟合/校准 | 现有v2 | 0/493 | 2/75 |
| 全部十篇，含拟合/校准 | 最难人工排序 | 0/493 | 0/75 |

嵌套留出的4次最难人工误报均为P10同一个人工窗口在原版及3份混合版本中的重复，仅1个正文hash，不是4个独立来源。它仍违反零观察误报要求。P07/P08的58个人工窗口包括原版19个及混合版本39个；旧指南中的0/19仅统计原版。

三类目标最终都选L2=1；只有普通存在判别在非嵌套选择折合计零误报，同时0/51命中。对“完整内层选参流程”的外层核验也是4/390误报、0/51命中，不能将选择折上的零误报解释为稳定泛化。

冻结后三种新函数全材料均为0/75混合段命中，单独生成段也为0/75。补做去除门限余量的事后诊断仍为0/75；即使使用全部已见人工标签确定零误报排序界限，仍为0/75。该诊断没有修改任何模型或冻结门限。

本轮失败结论限于预声明的五分数、线性函数和平滑目标，不证明所有可能的融合都无效。按原停止条件结束此轮搜索；更丰富的专业人工难例、匹配生成例与底层适配仍在[后续事项](../toDo/english-calibration-validation.md)。
