# 专业英文四模型的融合重调

2026-10-04，用户要求在[四模型接入](english-specialized-validation.md)之后重新调试英文融合。已完成全部目标资料打分、42候选实验以及发现微小分数裁剪问题后的75候选精度对照。**仍未达到完全人工窗口零误报、混合生成段召回50%的目标；默认保留英文v2。**本轮未改权重、运行profile、接口或服务版本。

## 数据与评价口径

沿用10篇原版、30份混合文档、75处单独生成段，共115输入、678个1600/400字符窗口。开发八篇590窗口对应365个不同正文hash，P07/P08的88窗口对应57个hash，合计422个不同输入分别运行四个新模型，共1688次模型／片段评分。旧九分类器分数从revision、正文hash和分片完全一致的缓存复用；四新模型的聚合分及多分类原始输出重新本地计算，推理时阻断网络。

用户口径：完全人工窗口被判正才是假阳性，包括混合文档中的完全人工窗口；含任意生成字符的窗口判正即正确，允许同窗人工内容。一个混合生成段与至少一个判正窗口有正长度交集即算命中，另报生成字符覆盖和单独生成段检出。

拟合六篇、人工门限校准两篇、P07/P08复测的论文组不变。拟合使用原版与混合窗口，孤立生成段只用于评价；同论文正文去重并保留全部bag归属，排除冲突标签及跨论文重复。各训练折重建标准化、系数和纯人工门限；校准正例不参与候选选择或门限。所有十篇已知结果，不能称为新的独立测试。

## 两轮实验

首轮42候选比较四新模型聚合分、七个细分类别信号、与v2五模型的两种组合、与全部旧九模型的类别组合。每组使用普通窗口存在判别和最难人工bag排序，各三档L2；另设v2重拟合和九个单信号对照。预测只读锁定模型的原始输出，来源、长度及位置仅服务拟合和评价。

初轮发现原有`1e-5`概率裁剪抹平了所有开发FollowSci分数和大部分CoCoDet类别分数。开发组完全人工435窗口、混合正例87窗口的FollowSci分数全部低于该界；CoCoDet AI类分别435/435、86/87低于该界。首轮证据保留不改，随后另行预声明75候选，对比保留微小分数的native logit和直接概率输入。native logit对概率及补概率分别以`1e-30`封底；单信号不再受到旧标准化裁剪的影响。数值实现和有限性检查均有测试。

两轮各做六论文选择折和完整嵌套留出。外层论文不进入内层选参、标准化、bag、系数或门限；最终只用拟合与校准纯人工最大分加预声明余量。各类冠军和总体选择在复测前冻结。精度对照已知首轮复测结果，明确属于后续开发诊断，未包装为独立验证。

## 结果

| 范围／配置 | 完全人工窗口误报 | 混合生成段命中 |
|---|---:|---:|
| 首轮完整选择流程：嵌套留出 | 14/390 | 4/51 |
| 精度对照完整选择流程：嵌套留出 | 24/390 | 8/51 |
| 首轮开发选择优胜者：P07/P08复测 | 0/58 | 0/12 |
| 精度对照开发选择优胜者：P07/P08复测 | 0/58 | 0/12 |
| 现有v2：P07/P08复测 | 0/58 | 2/12 |

首轮开发选择优胜者为CoCoDet AI类别单信号；精度对照为全部旧九分类器加七个专业类别信号的直接概率线性存在判别。非嵌套选择折参与选参，不能代替上表完整选择流程的嵌套结果。

首轮14次嵌套误报均来自P10，只有4个不同正文hash；精度轮24次来自P01/P02/P10，只有8个不同hash。重复正文在原版及派生版本中仍各计实际窗口，但不能当作独立来源。

精度轮另两类冻结冠军复测命中1/12、人工误报0/58，仍低于v2的2/12；没有按复测结果换选它们。所有材料合计的最高混合段命中为15/75，来自native-logit全信号最难人工排序，包含拟合数据，仅能作为开发拟合描述。

P07/P08的58个人工窗口包括原版19个、混合版本中的39个。两个总体选择的单独生成段复测也均0/12，v2为3/12。新方案没有表现出稳定的零误报检出优势。

事后固定函数门限诊断不用于回改参数：精度轮优胜者即使用全部已知人工标签确定零误报界限，也仅命中7/75混合段；降低到38/75命中时，有66/493完全人工窗口误报。此处只说明该固定评分的排序冲突，不是新校准或独立测试。
