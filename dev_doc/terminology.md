# 术语

| 术语 | 本项目含义 |
|---|---|
| 模型 ID | 本地接口稳定名称，例如 `hc3-zh` |
| repo_id / revision | 官方 Hugging Face 仓库及精确 commit |
| 原始 AI 分数 | 单个分类器 AI 类softmax、声明的多分类类别和或单输出sigmoid；全文值为窗口聚合分数，未校准 |
| 统计后端 / 原始统计量 | 本地因果LM输出进入Fast-DetectGPT或Binoculars公式；方向不同、不是概率，不单独分档；扩展融合须锁定资产/算术配置，当前英文v2未选入 |
| 强信号分 / `ensemble_score` | 十模型原始分数经融合强头计算的筛查分；v1 为唯一综合分，v2 保留此字段表示强头，均非概率或来源证明 |
| 复核分 / `review_score` | v2 以 CNKI 显著和疑似的并集比例拟合的另一筛查分；有独立门限，不能与强信号分混用 |
| 双头融合 | 同一组原始模型分数进入强头和复核头，先判强档，其余片段按复核头判疑似；两个头不是互斥类别概率 |
| 融合 profile | 固定模型 revision、标准化参数、特征项、各头系数、截距和门限的配置文件 |
| 分档线 / 门限 | 标注把分数变成筛查档位的界限；新策略读取融合 profile，旧策略默认原始门限为 0.90/0.70 |
| token | 某个模型 tokenizer 的编码单元，不等于汉字数 |
| 窗口 / chunk | 含特殊符号的推理片段，分类器通常最多512 token，MAGE最多4096、CoCoDet最多2048；统计后端默认512 |
| 字符位置 | 原 Python 字符串的 0 起点半开区间索引 |
| 覆盖权重 | 原 token 在覆盖它的窗口之间分摊的聚合权重 |
| smoke test / 试跑 | 确认安装和调用流程能运行，不能据此推断准确率 |
| 离线推理 | 模型已下载后，计算时没有网络依赖 |
| 标注片段 | 按自然边界划分、独立检测并赋标签的连续原文，默认最多 400 字符 |
| 默认融合策略 | `thesis-cnki-20260929-v2`；完整十模型、400/120 分片、固定 revision，双头分别判定强信号与疑似；v1 可显式选择 |
| 旧敏感规则 | `sensitive-any-model-v1`；任一所选模型达到原始分档线就突出该片段，并保留其他模型的分歧 |
| 其他 | 当前规则未触发的片段，包括不可编码内容；不认证为人类写作 |
| 报告包 | 带源文本、JSON、JSONL、HTML 和 COMPLETE 标记的可追溯结果目录 |

英文参考策略 `english-academic-20261003-v1`：四模型、1600/400分片和固定revision；强/复核共用同一分数函数而门限不同，0/19人工误报及0/12生成检出仅指本轮冻结测试。其“低误报优先”是操作点选择目标，不能解释为已验证一般低误报率或可靠排除AIGC。

英文扩展策略english-academic-20261003-v2：新五分类器、1600/400、schema3.0与固定revision；强/复核共用线性函数、门限不同。重新利用混合上下文并比较全部九分类器/三统计输出；旧19/12仅为两篇论文的片段数。P07/P08重复评估0/19人工误标、3/12生成段命中、20.38%混合生成字符覆盖，不是新的独立验证，未标记不能排除AIGC。

英文非线性实验english-academic-20261004-v3：schema4.0的固定RBF/tanh网络，只读原始分数；最终新五分类器/1600/400/4隐藏单元，两个头同函数不同门限。冻结复测1/12单独生成段命中、混合覆盖0，低于v2，故显式可选且不是英文默认。每模型贡献为精确分摊记账，不是因果重要性或作者概率。

`class_scores`：保留多分类各类别的未经校准softmax输出；窗口/全文聚合不是文本组成比例。CoCoDet的human/mix/ai指实质内容来源，DetectAIve区分纯人工、人工机器润色、机器生成及机器生成后机器人性化；ai_score_classes明确本包装器求和类别。
