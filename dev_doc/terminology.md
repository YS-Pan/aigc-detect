# 术语

| 术语 | 本项目含义 |
|---|---|
| 模型 ID | 本地接口稳定名称，例如 `hc3-zh` |
| repo_id / revision | 官方 Hugging Face 仓库及精确 commit |
| 原始 AI 分数 | 单个分类器 AI 类 softmax 输出；全文值为窗口聚合分数，未校准 |
| 综合筛查分 / `ensemble_score` | 十模型原始分数经版本化 profile 的正则化 logit stacking 得到的分数；不是概率或来源证明 |
| 融合 profile | 固定模型 revision、标准化参数、各模型系数、截距和综合门限的配置文件 |
| 分档线 / 门限 | 标注把分数变成筛查档位的界限；新策略读取融合 profile，旧策略默认原始门限为 0.90/0.70 |
| token | 某个模型 tokenizer 的编码单元，不等于汉字数 |
| 窗口 / chunk | 最多 512 token（含特殊符号）的推理片段 |
| 字符位置 | 原 Python 字符串的 0 起点半开区间索引 |
| 覆盖权重 | 原 token 在覆盖它的窗口之间分摊的聚合权重 |
| smoke test / 试跑 | 确认安装和调用流程能运行，不能据此推断准确率 |
| 离线推理 | 模型已下载后，计算时没有网络依赖 |
| 标注片段 | 按自然边界划分、独立检测并赋标签的连续原文，默认最多 400 字符 |
| 默认融合策略 | `thesis-cnki-20260929-v1`；完整十模型、400/120 分片、固定 revision，综合分由 profile 门限分档 |
| 旧敏感规则 | `sensitive-any-model-v1`；任一所选模型达到原始分档线就突出该片段，并保留其他模型的分歧 |
| 其他 | 当前规则未触发的片段，包括不可编码内容；不认证为人类写作 |
| 报告包 | 带源文本、JSON、JSONL、HTML 和 COMPLETE 标记的可追溯结果目录 |
