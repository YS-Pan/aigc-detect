# 自动维护触发条件

- 更换模型 revision 或标签适配：核对作者推理代码，更新 manifest，重新运行哈希检查、离线试跑和单窗口公式比较。
- 升级 PyTorch / Transformers：重新记录依赖锁，验证 catalog 全部模型加载与 CPU/CUDA 行为。
- 改分块或接口：验证全文覆盖、Unicode 位置、参数拒绝和真实 HTTP 调用，更新用户约定。
- 默认融合绑定模型 revision、完整模型列表和分段规则；这些输入或正文提取方式变化时，重新做参考比较和留出检查，发布新的融合配置版本。不能沿用旧配置的验证结论。

只在相关变更发生时执行；当前没有注册自动化、后台轮询或定时任务。
